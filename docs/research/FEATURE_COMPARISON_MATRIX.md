Rules used to fill this matrix:

- Every cell states only facts recorded in the two source audits. Nothing is inferred from marketing pages or memory.
- **"not stated in audit"** — the audit of that repository contains no evidence about this capability. Nothing has been inferred.
- **"not verified"** — ClipForge's current state for this capability is not documented in the source audits; the honest answer is recorded instead of a guess.
- The **ClipForge** column reflects the current repository state as of 2026-11-16: single-moment picker, faster-whisper transcription, karaoke ASS captions, MediaPipe reframe, Argos translate, no MCP server yet, no tests yet.

## What ClipForge adopts and from where

Ground rules for adoption, per repository:

1. **PeakCut (MIT) — directly adoptable ideas, and code with the MIT notice retained.** Adopt: loudness-per-second z-scoring and the (LOUD) line marks; the window/overlap loop with per-window candidate quotas; the `_snap()` sentence-finish boundary repair (including pause-based sentence ends for unpunctuated transcripts); the 30 %-overlap dedup; `_tidy()` output clamping; the loudness-only deterministic fallback; the `_same_word`-guarded caption wording fix with the 1:1 word-count contract; evenly-spread translation timing (`_spread()`); the per-word measured ASS pop-caption approach. Swap its Parakeet-specific ASR for faster-whisper while keeping the word-timestamp contract.
2. **SupoClip (AGPL-3.0) — clean-room ideas only; no prompt text and no code reuse.** Adopt as concepts reimplemented from behavioral descriptions: unit-id transcript addressing with timestamps computed in code; the four 0–25 anchored virality subscores; windowed analysis with overlap dedup by ratio; snap-to-transcript-line tolerance plus mechanical duration repair; one-clip-per-N-minutes budgeting; the comparative rerank with non-increasing score clamping and subscore rescaling; deterministic signal-weight pre-ranking fed into prompts; judge/critique pass loops returning structured fixes; template-dict caption styling; deterministic, rate-limited emoji injection. No verbatim prompt or code from supoclip enters this repo.
3. **perfect-srt (no license) — clean-room reimplementation required.** Adopt as architecture, reimplemented independently for vertical-video defaults: the timing skeleton with index-range addressing so corrected cues cannot drift; a coverage checklist with a numeric threshold; a mechanical-only repair pass that never rewrites wording; hard pass/fail output gates (the G1–G7 shape) that block writing the file; a canonical/variant glossary with a banned-substring gate and a quantified before/after census; the ♪ policy for unrecoverable spans. Re-tune the broadcast-style defaults (2 lines / 62 chars / 0.8–7.5 s) for vertical video. Nothing is copied — no code, no prose, no names-pack content.
4. **OpenShorts (MIT core; `cloud/` commercial-licensed and off-limits) — selective adoption, MIT paths only.** Adopt: the MCP server design patterns (in-process `httpx.ASGITransport` callbacks so tools cannot drift from REST, a stdio twin of the same handlers, a `server.json` manifest, protocol test files); agent skill patterns (async-first loop, HMAC webhook signing, "wrong tool" honesty, self-host detection); stdlib-pure selection helpers kept unit-testable without heavy video dependencies; the continuous-measurement layout picker; word-timestamp merging and the ASS ffmpeg filter-escaping lessons; transcription backend fallbacks (GPU/CPU, whisper fallback). Never copy, vendor, or link `cloud/` as a dependency.
5. **lemo-opuscar (MIT code; agent-facing docs CC BY-NC 4.0) — practices transfer, text must be rewritten.** Adopt as practices, implemented in original words: the router-style AGENTS.md with a request→document table and a single canonical imported file; a machine-parseable, idempotent setup entrypoint that prints a final machine-readable line; tiered dependency install with sizes stated; one clarifying round then sensible defaults; the deterministic artifact contract (output a pure function of time, machine-checkable events); machine-verifiable quality gates with exit codes that block delivery on failure; read-only asset library vs writable project folder; a dependency lock for concurrent agent sessions; generated-doc blocks between markers with a single metadata source; provenance discipline (delivery incomplete without credits naming every third-party asset and license). No AGENTS.md/DIRECTOR.md/TECHNIQUE.md/STYLE.md prose is copied.
6. **Openclip — no adoption.** MIT-compatible but a dead end: hardcoded Windows ffmpeg paths, keyframe-inaccurate `-c copy` cutting, no tests/CI, dormant. Kept as a footnote; nothing is taken from it.

Known gaps in this matrix (recorded honestly rather than guessed): OpenShorts' audit contains no evidence on audio-based selection signals, candidate deduplication, boundary snapping, subtitle correction, or translation; supoclip's audit contains no evidence on translation; Openclip's audit contains no evidence on deduplication, subtitle correction, or translation; ClipForge's own deduplication, boundary snapping, audio-signal, and subtitle-correction state is not verified here and should be documented from the codebase separately.
